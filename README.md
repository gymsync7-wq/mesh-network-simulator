# 🌐 Mesh Network Simulator

A network topology simulator that visualizes routing algorithms across mesh networks in real time.

## 🛠 Tech Stack
- **Python** — core logic
- **NetworkX** — graph modeling & algorithm implementation
- **Flask** — web backend / API
- **Tkinter** — desktop GUI visualization

## ✨ Features
- Interactive mesh network topology builder
- Shortest path routing using **Dijkstra's Algorithm**
- Graph traversal using **BFS (Breadth-First Search)**
- Real-time network visualization
- Flask-powered backend for simulation control

## 🚀 Getting Started

git clone https://github.com/gymsync7-wq/mesh-network-simulator.git
cd mesh-network-simulator
pip install -r requirements.txt
python main.py
